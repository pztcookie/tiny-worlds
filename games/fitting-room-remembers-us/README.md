# The Fitting Room That Remembers Us · 记忆试衣间

把六张照片和一段共同经历放进有性格的试衣间，再把下一章交给朋友。

本目录保存 [Netlify 已发布版本](https://euphonious-tartufo-256954.netlify.app/) 的静态运行文件，取回日期为 2026-11-02。它与仓库中的 [`the-fitting-room`](../the-fitting-room/) 是不同作品：旧作通过穿衣、叠穿和镜子表达人生过渡；本作让两个人通过照片、回忆和寻物产生互动。

这是线上运行版本的恢复记录，不包含原开发历史或未发布的创作素材。`recovery-manifest.json` 列出来源、文件大小、SHA-256 与修改记录。

## 运行

在这个目录运行 `python3 -m http.server 8765`，然后打开 `http://localhost:8765`。无需构建、安装依赖、API key 或后端。保留原文件名 `app.js`，因为章节导出会读取它。

Google Fonts 是可选的外部字体；阻断字体请求时，界面使用系统字体，核心流程仍能运行。

## 实际玩法

1. 作者上传六张照片，填写双方名字和这一天的线索；也可使用虚构演示。
2. 房间把照片藏在衣架、镜子、杯子、衣服和帘子后面。作者依次探索，并写下每张照片对应的回忆。
3. 固定文字模板与关键词规则把这些片段组织成故事，为两人分配幻想角色。这里没有调用生成式 AI，也没有分析照片内容。
4. 作者可以保存 PNG；确认照片和文字后，可以导出一个含素材与数据的 HTML 文件，交给朋友。
5. 朋友进入第二章。照片被打乱藏进物件，点击后短暂显示；朋友把照片与作者写下的回忆配对。选错可以重试，进度不会清零。
6. 六段记忆配对完成，朋友可导出照片与文字的拼贴纪念图。

当前问题提示是预设的，朋友通过照片配对作答；尚未实现朋友自由撰写自己的记忆并回传给作者。

## 数据与交付边界

照片和文字保留在当前页面内存中，刷新会清空；这是恢复版本的既有行为，本次没有改为仓库其他游戏使用的 localStorage。

分享生成的是可下载的独立 HTML 文件，里面包含所选照片和文字，不是加密容器。没有自动创建私密网址、云端照片存储、跨设备同步、账号或支付功能。上传到此仓库的只有程序、SVG 美术与虚构演示，不包含用户在浏览器里添加的真实照片或回忆。

## 本次恢复的最小修复

原版将 CSS、故事数据和 JavaScript 作为 `String.replace` 的替换字符串嵌入章节。替换字符串会解释 `$` 标记，导致 `$$` 选择器变成 `$`，分享文件出现重复变量声明并停止运行；用户文字中的类似标记也可能被改写。

这里只把三处替换改成返回字符串的函数，保留文本原样。Netlify 网站未修改，原版 `app.js` 的哈希记录在恢复清单中。

## 可复用的方法：双人记忆接力

**现实材料 → 带有性格的藏物空间 → 作者补充意义 → 把探索权交给另一个人 → 共同纪念物。**

固定的是作者与收件人的两段流程、提示与重试、内容确认、最后可保存的结果；可替换的是照片、文字、空间、物件及人物关系。照片应决定互动和结果，不能只作为背景装饰。

这次不新建独立 skill。现有 `moment-to-mini-experience` 已覆盖日常物件、探索、玩家创作与带走结果；本 README 保留双人接力这个具体案例，等另一件不同主题的作品复用后，再决定是否抽成共用模块。
